Пакет для хранения и поиска учебных аудиторий с сохранением в JSON.

## Сущность

`Classroom` — dataclass со следующими полями:

- `id` — уникальный строковый идентификатор
- `name` — название
- `category` — категория
- `year` — год
- `area` — площадь
- `number_of_seats` — количество мест

При создании проверяются инварианты (непустые строки, положительная вместимость, допустимый год и т.д.).

## Каталог

Класс `Catalog` хранит аудитории в словаре по `id` и поддерживает:

- добавление, получение и удаление
- поиск по категории и по имени (без учёта регистра)
- итерацию, проверку длины и наличия

**Порядок итерации:** по возрастанию `id`.
